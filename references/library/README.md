# Reading library

Download papers here to read them. Everything in this folder except this
README is git-ignored: the papers belong to their authors and publishers, and
they are large.

To keep the library rebuildable on another machine, add a line to
`../library.tsv` for each paper you save here:

```
file<TAB>url<TAB>bibkey
```

`bibkey` is the paper's key in `../refs.bib`, once it has an entry.
